
# Portfolio Project Website

## Overview
This website is a project portfolio website that showcases my background, skills, achievements, and contact information for my Final Practical requirement.

## Features
- Responsive layout for desktop, tablet, and mobile.
- Navigation menu for easy browsing.
- Light and dark mode toggle.
- Saves theme preferences using Local Storage.
- Displays skills using JavaScript.
- Contact form with input validation.

## Technologies
- HTML
- CSS
- JavaScript
- Local Storage

## Setup
1. Download the project folder (final-practical-Bernardo).
2. Extract the project folder if it is compressed.
3. Open the project folder.
4. Find "index.html".
5. Open it using a web browser (Open with Live Server).

or

1. Input the website URL in your chosen browser.
